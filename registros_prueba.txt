REGISTROS DE PRUEBA - SISTEMA ACADÉMICO

========================================
¡IMPORTANTE!: SOLUCIÓN AL ERROR DE LLAVE DUPLICADA '0'
========================================
Si al pegar los registros te sale un error que dice "Entrada duplicada '0' para la clave 'PRIMARY'", 
significa que tus tablas no tienen activado el "Auto Incremento".

Para arreglarlo, copia y pega este bloque PRIMERO en la pestaña SQL:

ALTER TABLE `alumnos` MODIFY `id` int(10) NOT NULL AUTO_INCREMENT;
ALTER TABLE `docentes` MODIFY `id` int(10) NOT NULL AUTO_INCREMENT;
ALTER TABLE `materias` MODIFY `id` int(10) NOT NULL AUTO_INCREMENT;
ALTER TABLE `matriculas` MODIFY `id` int(10) NOT NULL AUTO_INCREMENT;
ALTER TABLE `inscripciones` MODIFY `id` int(10) NOT NULL AUTO_INCREMENT;
